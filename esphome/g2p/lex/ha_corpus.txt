# Home Assistant announcement corpus for the espeak-free lexicon G2P.
#
# Written for this port, not sampled from anything: the shapes a voice
# assistant in a house actually says. Contractions, digits, times,
# temperatures, percentages, device names and room names are all deliberate,
# because those are exactly where a dictionary-first front end can fail
# differently from espeak. Lines starting with '#' are comments.
#
# Blank lines are ignored.
